== WgetLogDigest

=== 解決すべき問題

HTTPステータス `200 OK` が応答されたURLには問題がないからさておくとして `404 Not Found` が応答されたURLには注意を払うべきでしょう。wgetのログの中から情報を抽出して `404 Not Found` が応答されたURLの一覧リストを作りたくなるでしょう。URLとHTTP応答ステータスがテキスト1行にレイアウトされていれば wgetのログを `grep` コマンドでフィルタするだけで必要十分なリストが得られるでしょう。

ところが上記のサンプルをみればすぐわかる、wgetのログの形式は *行指向* でありません。HTTP要求の情報とHTTP応答の情報が別の行に出力されている。このままではgrepコマンドで後処理することが難しい。困った。

=== 解決方法

wgetのログファイルを *行指向* のテキストファイルに変換するプログラムを作ろう。`WgetLogDigest` と呼ぶことにします。`WgetLogDigest` は下記のようなテキストを出力します。

```text
2026-10-23 22:03:04  http://www.myapp.jp/index.html  200  OK
2026-10-23 22:03:34  http://www.myapp.jp/member/index.html  200  OK
2026-10-23 22:03:35  http://www.myapp.jp/img/common/f_logo.png  200  OK
2026-10-23 22:03:36  http://www.myapp.jp/privacy/index.html  404  Not Found
2026-10-23 22:03:37  http://www.myapp.jp/img/index/page_top.png  200 OK
```

各行はTABで区切られています。

`yyyy-MM--dd hh:mm:ss` **\t** `URL` **\t** `status` **\t** `message`



=== 説明

わたしはJavaで `WgetLogDigest` を開発しました。GitHubでレポジトリを公開しました。

- link:https://github.com/kazurayam/WgetLogDigest[WgetLogDigest の GitHubレポジトリ]

Java/Gradle/Kotlinのビルドツール link:https://gradle.org/[Gradle]のカスタムプラグインとして WgetLogDigest を利用することができます。

Gradleの `build.gradle` のサンプルを下記に示します。ここでは wgetのログがファイルとして与えられたと仮定しています。ログを行指向フォーマットに変換し、出力されたテキストをOSのgrepコマンドでフィルタしています。

```gradle
plugins {
    id("com.kazurayam.wget-log-digest-plugin") version "0.1.11"
}

tasks.register('digest', com.kazurayam.wgetlog.DigesterTask) {
    wgetLogFile = file("../plugin/src/test/fixtures/wget.log")
    outputFile = file("./build/tmp/out/straight.txt")
}

import org.gradle.process.ExecOperations

interface InjectedExecOps {
    @javax.inject.Inject
    ExecOperations getExecOps()
}

tasks.register('listFaultyURLs') {
    dependsOn('digest')
    def injected = project.objects.newInstance(InjectedExecOps)
    def stdout = new ByteArrayOutputStream()
    doLast {
        new ByteArrayOutputStream().withStream { os ->
            def result = injected.execOps.exec {
                commandLine 'grep', 'Not Found', "./build/tmp/out/straight.txt"
                ignoreExitValue = true
                standardOutput = os
            }
            def outputFile = file("./build/tmp/out/faultyURLs.txt")
            outputFile.text = os.toString()
        }
    }
}
```

わたしが関係しているシステムで得られたwgetログにこのビルドを実行すると下記のような faulty URL のリストが得られました。
